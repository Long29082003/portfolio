Witch on Broomstick

Witch on Broomstick is a small side-scrolling action game developed as a personal project. Players battle enemies while trying to dodge projectiles to survive as long as possible. The project focuses on responsive controls, smooth animations, collision detection, and game state management.

Building this game helped me strengthen my understanding of JavaScript programming, object-oriented design, animation loops, and gameplay mechanics. It also introduced me to balancing game feel with technical implementation.
